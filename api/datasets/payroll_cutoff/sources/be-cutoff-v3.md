## Rule
For Belgian payrolls, all payroll changes must reach SD Worx at the latest 5 working days before payday.
Payroll changes include new hires, salary changes, absences, terminations, bonuses and one time payments.

## Late changes
Payroll changes received after the cutoff are processed in the next payroll run.
A correction run can be requested for the current month and is charged separately.

## Exceptions
Only urgent terminations with a final pay obligation can be processed after the cutoff, with approval from the team lead.
