## Rule
For Belgian payrolls, all payroll changes must reach SD Worx at the latest 3 working days before payday.

## Late changes
Payroll changes received after the cutoff are processed in the next payroll run.

## Exceptions
No exceptions are allowed after the payroll cutoff.
